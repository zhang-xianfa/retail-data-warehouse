门店销售额 TOP10

按业务日期与大区筛选，查看门店销售额排名，支持柱状图与饼图切换，并展示销量、订单数、客单价明细。

数据表：hui_min_dws.dws_store_sales_daily

商品品类与热销分析

商品品类销售占比、热销商品 TOP N、支付方式分布与各大区销售对比，四个图表同屏展示。

数据表：hui_min_dwd.dwd_trade_detail
